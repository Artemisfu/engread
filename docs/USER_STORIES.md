# EngRead 用户故事与优先级

## 产品目标

EngRead 是一个面向英语阅读学习的 Android 应用。它首先要成为稳定、轻量的英文书阅读器，然后在阅读现场提供词义、段落翻译和笔记沉淀能力。

设计方向：现代、简约、扁平化，颜色和反馈借鉴多邻国的亲和、明亮、低压力体验，但整体交互保持阅读应用应有的安静和专注。

## MVP / P0：可靠阅读闭环

1. 作为读者，我可以从 Android 文件选择器导入 `.txt` 和常见 `.mobi` 英文书籍，导入成功后进入书架。
2. 作为读者，我可以在书架看到书名、导入时间、最近阅读时间和阅读进度。
3. 作为读者，我可以打开一本书并以滚动方式阅读正文。
4. 作为读者，我退出后再次打开同一本书时，可以回到上次阅读的段落附近。
5. 作为读者，我可以选择字体、字号和主题偏好，并且设置会立即生效并保存。
6. 作为读者，我看到每个段落首个英文字符以大写加粗方式展示，但原文内容不被修改。
7. 作为读者，我可以删除书籍，删除前有二次确认。
8. 作为读者，我在导入失败、空书架、mobi 不支持或文件损坏时能看到明确提示，而不是应用崩溃。

### P0 验收标准

- TXT 至少支持 UTF-8、UTF-8 BOM、UTF-16LE/BE BOM。
- MOBI 支持常见无 DRM、PalmDOC 压缩文本内容；不支持的压缩或 DRM 文件给出清晰错误。
- 阅读进度以段落索引保存，不依赖页码。
- 大文件导入和阅读不阻塞主线程的关键 UI。
- 段首样式只影响段落首个英文字符；空白、引号、标点前缀不应破坏样式。

## P1：阅读现场学习能力

1. 作为读者，我可以长按单词，在底部看到单词、音标/读音入口和中文解释。
2. 作为读者，我可以对当前段落发起中文翻译，看到加载、成功、失败和重试状态。
3. 作为读者，我可以从段落中勾选一个或多个句子加入笔记本。
4. 作为读者，我可以给摘录句子添加自己的中文或英文笔记。
5. 作为读者，我可以进入笔记本列表，查看、编辑和删除笔记。
6. 作为读者，我可以导出笔记为 Markdown 或 TXT，内容包含书名、原句、笔记和时间。

### P1 验收标准

- 长按识别英文单词边界，底部词义卡片可以关闭。
- 本地词典没有释义时，显示降级提示，并保留后续接入词典 API 的扩展点。
- 翻译服务未配置时，不假装成功，应提示当前为演示翻译或需要配置服务。
- 笔记与书籍、段落索引和原句稳定关联。
- 导出失败时显示错误信息。

## P2：阅读效率增强

1. 作为读者，我可以搜索书内内容。
2. 作为读者，我可以查看目录或章节列表，快速跳转。
3. 作为读者，我可以获得更完整的 mobi 解析，包括章节、基础 HTML 清洗和编码兼容。
4. 作为读者，我可以选择更丰富的主题和排版设置，例如行距、页边距。
5. 作为读者，我可以从笔记跳回原书原段落。

## P3：长期学习系统

1. 作为读者，我可以登录并跨设备同步书籍元数据、进度和笔记。
2. 作为读者，我可以把笔记或查词记录生成背词练习。
3. 作为读者，我可以看到阅读天数、词汇量、笔记量等学习统计。
4. 作为读者，我可以使用云端词典、翻译和 AI 摘要能力，并清楚知道数据流向。

## 主要风险

- MOBI 格式复杂，第一版只承诺常见无 DRM 文本内容。
- 文本交互容易冲突：长按查词、句子勾选、段落翻译、系统复制菜单要保持层级清楚。
- 进度保存不能使用页码，应基于段落索引或文本位置。
- 词典和翻译涉及版权、API 成本和隐私，必须保留本地降级和配置入口。
- 大文件不能频繁全量重排或字符串匹配定位。
